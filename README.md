# CorporateDroneAIM

Если вы устали от рутинного клацанья мышкой во время работы, а часы, потраченные на задачи, — это упущенная возможность для тренировки аима в любимом шутере, то данная программа — лучшее решение!

С её помощью на вашем экране появится классный оверлей со стреляющим оружием и звуковыми эффектами!

Всё можно кастомизировать: от внешнего вида оружия до звуков выстрелов и падающих гильз!

---

## Установка

### Для обычных пользователей (рекомендуется)

1. Скачайте последний релиз с [GitHub Releases](https://github.com/KrechkoVsevolod201/CorporateDroneAIM/releases)
2. Запустите `CorporateDroneAIM_Setup.exe`
3. Следуйте инструкциям установщика
4. Программа создаст ярлык на рабочем столе и в меню Пуск

### Альтернативная установка (без установщика)

1. Скачайте `CorporateDroneAIM.exe` из релиза
2. Запустите файл
3. При первом запуске программа создаст папки `sounds/` и `assets/` рядом с exe

### Структура директорий

```
CorporateDroneAIM/
├── sounds/
│   ├── shot/          # Звуки выстрелов
│   └── shell/         # Звуки падения гильз
├── assets/
│   ├── weapons/       # Кастомные оружия (PNG)
│   └── gloves/        # Кастомные перчатки (PNG)
├── config.json        # Настройки (создаётся автоматически)
└── CorporateDroneAIM.exe
```

### Для разработчиков

```bash
# Клонируйте репозиторий
git clone https://github.com/KrechkoVsevolod201/CorporateDroneAIM.git
cd CorporateDroneAIM

# Установите зависимости
pip install -r requirements.txt

# Запустите программу
python main.py
```

## Сборка

### Сборка exe

```bash
# Запустите скрипт сборки
.\build_exe.ps1

# Или вручную
pip install pyinstaller
pyinstaller CorporateDroneAIM.spec
```

Готовый exe будет в папке `dist/CorporateDroneAIM.exe`

### Сборка инсталлятора

1. Установите [Inno Setup 6](https://jrsoftware.org/isdl.php)
2. Запустите:
```bash
.\build_installer.ps1
```

Инсталлятор будет в папке `installer_output/CorporateDroneAIM_Setup.exe`

## Инструкция по использованию

### Горячие клавиши

Программа работает через глобальные горячие клавиши, которые работают без фокуса на окне:

| Комбинация | Действие |
|------------|----------|
| **ЛКМ** (левая кнопка мыши) | Выстрел |
| **Ctrl+Shift+S** | Открыть настройки |
| **Ctrl+Shift+W** | Сменить оружие |
| **Ctrl+Shift+H** | Показать/скрыть подсказки |
| **Ctrl+Shift+Q** | Выход из программы |

### Основные функции

#### 1. Выбор оружия
- Встроенные модели: пистолет, винтовка, пистолет-пулемёт, дробовик, снайперская винтовка
- Возможность загрузить своё оружие (PNG с прозрачностью)

#### 2. Настройка внешнего вида
- Размер оружия
- Позиция (смещение X/Y)
- Прозрачность окна
- Выбор рук (тактические, обычные, перчатки, кибер)

#### 3. Эффекты стрельбы
- Вспышка дула
- Трассер (сплошной, пунктирный, светящийся)
- Попадание в точку курсора
- Отдача
- Гильзы

#### 4. Прицел
- Стили: крест, точка, круг, крест с точкой, T-образный
- Настройка размера, толщины, зазора
- Выбор цвета и прозрачности

#### 5. Звуки
- Выбор звука выстрела
- Выбор звука падения гильзы
- Регулировка громкости
- Возможность добавить свои звуки (mp3/wav/ogg)

#### 6. Кастомные ассеты
- Загрузка своего оружия (PNG)
- Загрузка своих перчаток (PNG)
- Загрузка своих звуков

### Настройки

Откройте настройки через **Ctrl+Shift+S** или кнопку в системном трее.

#### Разделы настроек:

1. **МОДЕЛЬ** - выбор встроенного оружия и рук
2. **КАСТОМНЫЕ PNG** - загрузка своих ассетов
3. **ТРАНСФОРМ** - размер, позиция, прозрачность
4. **ЭФФЕКТЫ** - включение/выключение эффектов
5. **ПРИЦЕЛ** - стиль, размер, цвет
6. **ТРАССЕР** - стиль, толщина, длительность
7. **ЗВУК** - выбор и громкость звуков
8. **ПОДСКАЗКИ НА ЭКРАНЕ** - управление панелью помощи

### Мульти-монитор

Программа автоматически определяет, на каком мониторе находится курсор, и перемещает оверлей на этот монитор.

### Важно знать

- Оверлей **не перехватывает клики** - вы можете кликать сквозь него
- Все настройки сохраняются автоматически в `config.json`
- При первом запуске создаются папки `sounds/` и `assets/` рядом с exe
- Для работы требуются права администратора (для глобальных горячих клавиш)

## Требования

- Windows 10/11 (x64)
- Python 3.10+ (для разработки)
- Права администратора (для глобальных горячих клавиш)
